# Mission Plato

A personal agentic learning system designed to teach me high-impact topics 
(business, economics, investing, coding, AI, money) with maximum depth and precision.

## 40-Day Goal

- Build a cross-device AI agent that:
  - Learns my interests and knowledge level
  - Generates a personalized curriculum
  - Teaches me daily with lessons and quizzes
  - Tracks my mastery over time
  - Is accessible from all my devices
